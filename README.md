# 💼 CareerConnect – Job Seeker Website

**CareerConnect** is a responsive job portal website designed to help job seekers explore job opportunities, search and filter listings, save their favorite jobs, and find information about career opportunities.

🌐 **Live Website:** https://agashya03.github.io/job-seeker/

📂 **GitHub Repository:** https://github.com/agashya03/job-seeker

## ✨ Features

- 🏠 **Home Page** – Welcoming landing page for job seekers.
- 🔍 **Job Search** – Search for jobs using keywords and locations.
- 🎯 **Job Filters** – Filter opportunities by category, work type, and experience.
- 📄 **Job Details** – View detailed information about job openings.
- ❤️ **Saved Jobs** – Save and revisit interesting job listings using browser local storage.
- 📱 **Responsive Design** – Layout designed for desktop and mobile screens.
- 🎨 **Animations and Hover Effects** – Smooth visual transitions and interactive elements.
- 📬 **Contact Page** – Contact form interface for visitor inquiries.
- ℹ️ **About Page** – Information about the CareerConnect platform.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/agashya03/job-seeker.git
```

### 2. Navigate to the project

```bash
cd job-seeker
```

### 3. Run the website

Open `index.html` in your web browser.

For local development, you can also use the **Live Server** extension in Visual Studio Code.

## 🌐 Deployment

This project is hosted using GitHub Pages.

Live URL: https://agashya03.github.io/job-seeker/

To publish updates:

```bash
git add .
git commit -m "Update CareerConnect website"
git push origin main
```

Configure GitHub Pages to deploy from the `main` branch and the root directory (`/`).

## ⚠️ Project Limitations

- Job listings are sample data for demonstration purposes.
- The website does not currently use a backend database or authentication system.
- Saved jobs are stored in the browser using local storage.
- Job applications and contact form submissions are not sent to a real server.
